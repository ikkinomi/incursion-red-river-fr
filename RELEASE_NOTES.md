# Version 0.1.0 bêta — 8 novembre 2026

Première publication du patch français pour **Incursion Red River 1.4.0.1**, build Steam **26487830**.

Le joueur a confirmé que les menus et les missions s'affichent correctement en français. Le jeu charge bien l'archive de traduction. Les 6 670 entrées et les variables ont été contrôlées après compilation.

L'archive ZIP contient le dossier `Test_C` à copier dans le dossier du jeu et une notice. Gardez la langue **English / Français (patch)**.

Cette version repose sur une traduction automatique locale, avec 1 383 textes distincts corrigés manuellement. Des formulations approximatives peuvent subsister dans les longs textes. Les voix ne sont pas traduites et tous les écrans ne sont pas encore validés.

Pour désactiver : fermez le jeu et renommez uniquement `pakchunk99-French_P.pak` en `pakchunk99-French_P.pak.disabled`.
