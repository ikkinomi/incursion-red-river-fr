# Crédits

- Jeu original : Incursion Red River. Les textes, noms et marques du jeu restent la propriété de leurs ayants droit.
- Préparation du patch et corrections françaises : projet communautaire publié par ikkinomi, avec l'assistance de Codex.
- Base de traduction locale : modèle OPUS-MT anglais-français distribué par Argos Translate. Modèle d'origine sous CC BY 4.0.
- Référence du modèle : Jörg Tiedemann et Santhosh Thottingal, « OPUS-MT — Building open translation services for the World », EAMT 2020.
- Distribution du modèle : https://github.com/argosopentech/argospm-index
- Extraction et création des archives : [repak](https://github.com/trumank/repak).
- Export et import des ressources de langue : [UnrealLocres](https://github.com/akintos/UnrealLocres).

Les exécutables de ces outils, le modèle de traduction, les sauvegardes du joueur et les archives originales du jeu ne sont pas inclus dans cette publication.

Correction du widget et création de la table de catégories : utilisation de [UAssetAPI / UAssetGUI](https://github.com/atenfyr/UAssetAPI).
