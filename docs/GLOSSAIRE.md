# Glossaire de relecture

Conserver Incursion Red River, Quarry, Outskirts, Delta et Bunker lorsqu’il s’agit des cartes. Conserver les marques et modèles, dont Discord, NVIDIA Reflex, Boost, AK Star, Longbow, Team Wendy, Paraclete Origin et National Match.

| Anglais | Français | Contexte |
|---|---|---|
| Stock | Stock | Quantité disponible chez le marchand |
| Stock / Buttstock | Crosse | Pièce d’arme |
| Item | Objet | Inventaire et commerce |
| Attachment | Accessoire | Équipement |
| Dust Cover | Capot de culasse | Catégorie et pièce |
| Foregrip | Poignée avant | Accessoire |
| Sight | Organe de visée | Terme générique |
| Reflex Sight | Viseur reflex | Type de viseur |
| Buffertube | Tube de crosse | Pièce |
| Plate Carrier | Porte-plaques | Protection |
| Tactical Rig | Gilet tactique | Équipement |
| Barter / Salvage | Troc / Récupération | Marché |
| Story missions | Missions scénarisées | Tutoriel |
| Assignments | Contrats | Missions répétables FANG |
| Muzzle Velocity | Vitesse initiale | Statistique |
| Tourniquet | Garrot | Objet médical du jeu |

Le contexte prime : une étoile de mission peut se traduire, tandis que Star dans AK Star est conservé. Stamina Boost est un bonus d’endurance ; Boost dans NVIDIA Reflex est une appellation. Le nom de carte Bunker ne se confond pas avec le nom commun bunker.

Conserver les commandes du terminal, les noms de fichiers, ns, key, source, variables et balises. Les règles structurées se trouvent dans REGLES-TRADUCTION.json.

Ces règles sont désormais lues par [le contrôleur de maintenance](../maintenance/README.md). Les noms protégés et les invariants de format sont bloquants ; les divergences de glossaire restent des propositions de relecture. Par exemple, « Sight » traduit par « Viseur » peut être acceptable dans un libellé court : le contexte doit être vérifié avant de le remplacer par « Organe de visée ».
